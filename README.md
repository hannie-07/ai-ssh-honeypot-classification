# AI-Assisted Classification of SSH Honeypot Sessions

## Project Overview

This project investigates the use of Google's Gemini large language model to classify activity recorded by a Cowrie SSH honeypot.

The aim was to examine whether an AI model could interpret SSH session behaviour and assign meaningful security-related classifications based on recorded login events and command activity.

This was a controlled laboratory experiment using researcher-generated activity. It was not an analysis of live attacks or real-world attacker traffic.

## Research Objectives

1. Generate SSH session activity in a controlled Cowrie honeypot environment.
2. Extract relevant session information from Cowrie logs.
3. Review and assign behavioural labels to the collected sessions.
4. Submit session information to Gemini for classification.
5. Compare Gemini's predictions against the researcher's reviewed labels.
6. Evaluate the results and document the limitations.

## Tools and Technologies

- **Cowrie 3.1.1:** SSH honeypot.
- **Docker:** Containerised honeypot environment.
- **Kali Linux:** Research and analysis environment.
- **Python:** Data processing and evaluation.
- **Google Gemini API:** AI-assisted session classification.
- **Google Colab:** API experimentation and prediction generation.
- **CSV and JSON:** Data storage and analysis.

## Experimental Environment

Cowrie was deployed in a local Docker environment and accessed through the local loopback address on port 2222.

The experiment generated 51 unique SSH sessions through controlled connection attempts, login activity and simulated command execution.

The sessions were generated by the researcher. They should not be interpreted as 51 independent attackers.

### Classification Results

Gemini's predictions matched all 51 researcher-reviewed reference labels, giving an observed agreement of 100% (51/51).

| Class | Precision | Recall | F1-score | Support |
|---|---:|---:|---:|---:|
| reconnaissance | 1.00 | 1.00 | 1.00 | 2 |
| brute_force | 0.00 | 0.00 | 0.00 | 0 |
| malicious_command_attempt | 1.00 | 1.00 | 1.00 | 18 |
| insufficient_evidence | 1.00 | 1.00 | 1.00 | 31 |

The script reports a four-class macro average of 0.75 for precision, recall and F1. This includes `brute_force`, which had zero support and was assigned zero scores. The three classes with observed examples each achieved an F1-score of 1.00, giving a macro F1 of 1.00 across those three evaluated classes.

The weighted average was 1.00 for precision, recall and F1.

**Important:** The 100% agreement applies only to this small, controlled dataset and its researcher-reviewed labels. It does not establish equivalent performance on real-world SSH traffic. The `brute_force` class was not evaluated because the dataset contained no failed-login events.

## AI Classification and Evaluation

Session information was supplied to Google's Gemini model through its API. Predictions were saved and matched to the researcher's reviewed labels using session IDs.

The evaluation script uses Python's built-in `csv` and `pathlib` libraries. It generates a classification report and confusion matrix without requiring external Python packages.

### Results

- Total matched sessions: 51
- Agreement with researcher-reviewed labels: 100%
- Macro average F1-score: 0.75
- Weighted average F1-score: 1.00

The confusion matrix showed agreement across all 51 evaluated sessions.

The macro average was affected by the brute-force category having zero support. No conclusion about Gemini's ability to detect brute-force activity can be drawn from this experiment.

## Important Limitations

1. **Small dataset:** Only 51 sessions were evaluated.
2. **Controlled activity:** The sessions were generated by the researcher in a local laboratory environment.
3. **Class imbalance:** The dataset contained no brute-force examples.
4. **Repeated patterns:** The 18 malicious command attempt sessions shared a repeated command sequence.
5. **Human-label limitations:** The reference labels were assigned and reviewed by the same researcher, rather than independently by multiple analysts.
6. **Model confidence:** Gemini reported high confidence for all predictions. These confidence values were not independently calibrated.
7. **Limited generalisation:** Agreement on this dataset does not establish performance on real-world SSH attacks.

## Conclusion

The experiment demonstrated that Gemini could reproduce the researcher's reviewed classifications across the 51 sessions in this controlled dataset.

However, the result should be interpreted as agreement with the reference labels rather than proof of general detection accuracy.

Further work should include a larger and more diverse dataset, independently reviewed labels, valid brute-force examples and testing against additional session patterns.
